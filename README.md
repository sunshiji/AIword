# AIword
能自动将大模型生成的文字变换格式。
## 功能特性
### 1. 核心功能
- 智能识别 Markdown 表格 ：自动识别剪贴板中的 Markdown 表格，一键粘贴到 Excel/WPS 表格
- 智能识别 HTML 富文本 ：支持从网页复制的 HTML 内容，正确转换格式后粘贴到 Word/WPS
- Markdown 格式转换 ：支持 ~~删除线~~ 、 **粗体** 、 *斜体* 、 `代码` 等格式自动转换为 HTML
### 2. 快捷功能（系统托盘菜单）
- 当前全局热键 （只读显示）：显示当前设置的热键及状态
- 启用热键 ：可开/关全局热键
- 设置热键 ：图形界面录制并保存新的全局热键（即时生效）
### 3. 设置选项
- 弹窗通知 ：开/关系统通知
- 无应用时动作 ：可选 - 自动打开 / 仅保存 / 复制到剪贴板 / 无操作
- 插入后移动光标到末尾 ：插入内容后自动将光标移动到末尾
- HTML 格式化 ：Markdown 样式自动转换为 HTML 标签
- 保留生成文件 ：勾选后生成的 DOCX/XLSX 会保存在 save_dir
### 4. 工具菜单
- 打开保存目录 ：快速打开文件保存目录
- 查看日志 ：打开日志目录查看运行日志
- 编辑配置 ：直接打开配置文件进行编辑
- 重载配置/热键 ：重新加载配置文件
### 5. 版本与更新
- 显示当前版本 ：托盘菜单显示版本号
- 检查更新 ：可手动检查更新
- 新版本提示 ：检测到新版本时显示下载入口，可点击打开下载页面
### 6. 退出
- 点击托盘菜单的"退出"可关闭程序
## 使用方法
### 1. 安装依赖
```
pip install -r requirements.txt
```
### 2. 运行程序
```
python main.py
```
程序启动后会在系统托盘显示图标，右键点击图标可查看完整菜单。

### 3. 默认热键
- 默认热键： Ctrl+Alt+V
- 按下热键会自动读取剪贴板内容并智能粘贴到活动的 Word/WPS/Excel 文档
## 配置文件说明 (config.json)
```
{
  "version": "1.0.0",              // 当前版本
  "hotkey": "ctrl+alt+v",          // 全局热键
  "hotkey_enabled": true,           // 是否启用
  热键
  "notification_enabled": true,     // 是否启用
  通知
  "no_app_action": "copy_to_clipboard",  // 无
  应用时的动作
  "move_cursor_to_end": true,       // 插入后移
  动光标
  "html_formatting": true,          // HTML格
  式化
  "keep_generated_files": false,    // 保留生成
  文件
  "save_dir": "./output",           // 保存目录
  "log_dir": "./logs"               // 日志目录
}
```
